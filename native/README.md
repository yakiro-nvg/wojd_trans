# Native localization component

Use build.cmd runtime or dump with MSVC x64 Build Tools. Test profiles expose fixture-only exports and must never be distributed. test_runtime.py checks an independent synthetic decoder/allocator, the full dictionary, source/origin guards, original export forwarding, concurrent calls and entry restoration. It never executes captured game code.

Runtime performs exact-source substitution on decoded data strings without per-string hit collection. Dump adds deduplicated captures/counters and the public archive helper. Optional incoming player chat translation calls the selected cloud service over HTTPS; it does not expose a remote command endpoint or bypass resource signatures. Documentation intentionally omits interception recipes.

Chat defaults off and supports Google Translate web, DeepL API, DeepSeek API and Gemini API. Settings select a default provider/model plus optional overrides per reviewed player channel. System, recruitment and unknown channels are excluded at both Lua and native admission. Each used provider has a separate Windows CurrentUser DPAPI key with provider-specific binding; production never reads a development loopback configuration. The worker performs network I/O; UI callbacks only exchange bounded copies. Cache keys include provider/model, with 1024 entries by default (16–8192 configurable), ten-minute idle expiry and LRU eviction. Payloads are dynamically allocated under a 64 MiB combined cap; hits extend expiry and shutdown clears them. LLMs return a bounded array of translated prose spans; native code inserts exact source rich-text anchors without filtering translations by their numeric spelling. This does not certify translation meaning. Errors annotate their affected original row with a [WOJD] separator, without automatic provider fallback or raw content/key logging. See [the player guide](../distribution/CHAT_GUIDE.txt) for privacy, key exposure precautions and current price references.

Dump currently captures the generic data route; dynamic typed Skill/Buff capture is disabled. Player ZIPs contain only the optimized runtime build with WOJD_CAPTURE=0 and WOJD_SELFTEST=0. Dump and test DLLs are never packaged for players.

Independently validated display fields read by a separate tooltip FString serializer also use the source-exact native dictionary. Runtime replacement and diagnostic capture remain separate build choices. Captured observations record archive completion as unverified and remain excluded from automatic native catalog import. Synthetic fixture success does not establish client coverage or installation timing.

The proxy forwards original DbgHelp exports to a local copy of the user's original DLL; that DLL is not distributed. Cached locations are hints and require current signature/origin validation. The portable installer checks x64 client structure and owned payload integrity; it does not reject a client merely because its EXE hash, timestamp or size changed.

vendor/minhook is 1.3.4 under its included BSD license, with tested local allocation modifications. Real-client validation remains required; thread patch coordination is not a zero-race/crash guarantee.

Public CI compiles runtime, dump, runtime-test and dump-test directly from this checkout. Production packages use only freshly compiled non-test DLLs. After building runtime-test, run `python native/test_c8_setup.py` for 95 independent allocator, notice, full-group, immutable-origin and actual MinHook setup checks. Chat wire, cache/key and LLM contract fixtures run during the test build. These fixtures use private synthetic memory and never execute captured code or open the game. Optional current-code diagnostics remain disabled by default.

Player-name glyphs compose all 26,972 local readings solely from the main UI League Spartan outlines, preserving every existing glyph and metric. MVH supplies the starting reading table, with credited dictionary supplements and explicit corrections of known semantic translations; no MVH or XF outlines are imported. Unmapped characters retain the original game CJK fallback. The same scoped font covers party/raid fields, UMG and current XingMingBan overhead names, and Txt_BuffSource_name in the buff tooltip. Chat shows the sender reading as 【name】 under VI. Original prefixes, PC_Name styling and player-link attributes remain unchanged. Player links mentioned inside VI gain 【reading】 beside the intact link; item links and emoji are untouched. No reading-only row is added when cloud chat is disabled. Generated headers and fonts are reproducible from public inputs.
